03 · How it works

Four small steps, and none of them touch your data.

  1. 1

    Detect

    A strict pattern finds $5, $1,299.99, US$49, USD 49 and 49 USD. It skips anything it can't be sure about, like CA$, negatives, broken grouping and $10abc.

    content/detector.js
  2. 2

    Price

    The background worker gets SOL/USD from Coinbase, with Kraken as a fallback. Quotes are cached for five minutes and refreshes are limited to one a minute. If no real quote is available, nothing gets converted.

    background/service-worker.js
  3. 3

    Replace

    Each amount gets wrapped in its own small inline span. Parent innerHTML, form values and the page's own JavaScript are never changed, so links and listeners keep working.

    content/converter.js
  4. 4

    Watch & restore

    A batched MutationObserver catches prices the site adds later, without polling. The exact original text is saved, so Restore puts it back character for character.

    content/content.js

What it never touches

Text you type, code and data in the page are all skipped, so nothing breaks.

  • Inputs & textareas
  • Selects
  • Editable text
  • Code & pre blocks
  • Hidden text
  • SVG & canvas
  • Other currencies
  • Banks, brokers & exchanges

04 · Privacy

No wallets. No tracking. Just SOL.

The only network calls the extension makes are for the SOL price. It doesn't send page content, URLs or browsing history anywhere. It has no analytics, accounts or remote code, and the extension makes no claims about trading.

storage
Your settings and the price cache. Local only, nothing synced.
activeTab
Reads the current hostname only while the popup is open.
Site access
Needed to change price text on normal websites.
2 price APIs
Coinbase spot price, with the Kraken ticker as a fallback.

05 · Install

Running in under a minute.

There's no build step, no API key and no account.

Get the code on GitHub
  1. Download or clone the repository.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the folder with manifest.json.
  4. Pin SOLify and reload any tabs that were already open.
